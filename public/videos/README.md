# Videos Directory

## Video File Name

Place your video file in this directory with the following name:

**`essaouira-promo.mp4`**

## Video Requirements

- **Format**: MP4 (recommended) or WebM
- **Recommended Resolution**: 1920x1080 (Full HD) or 1280x720 (HD)
- **Recommended Duration**: 1-3 minutes for promotional videos
- **File Size**: Try to keep under 50MB for better loading (you can compress the video)
- **Codec**: H.264 for best browser compatibility

## Supported Formats

- `.mp4` (recommended - best browser support)
- `.webm` (good compression, modern browsers)
- `.ogg` (fallback option)

## How to Add Your Video

1. Prepare your video file
2. Name it: `essaouira-promo.mp4`
3. Place it in: `public/videos/essaouira-promo.mp4`
4. Refresh your browser - the video will play when clicking "Watch Video" button

## Alternative: Using YouTube/Vimeo

If you prefer to host the video on YouTube or Vimeo, we can update the component to use an embedded player instead.
