# Images Directory

Place your images in this directory. The following images are expected:

## Hero Section Images (1920x1080 recommended)
- `hero-1.jpg` - Main hero slide 1
- `hero-2.jpg` - Main hero slide 2
- `hero-3.jpg` - Main hero slide 3
- `hero-4.jpg` - Main hero slide 4
- `hero-5.jpg` - Main hero slide 5
- `hero-6.jpg` - Main hero slide 6
- `hero-7.jpg` - Main hero slide 7

## Experiences Section Images
- `experience-1.jpg` - Experience image 1 (800x600 recommended)
- `experience-2.jpg` - Experience image 2 (800x600 recommended)
- `experience-3.jpg` - Experience image 3 (1200x600 recommended)

## Image Requirements
- Format: JPG, PNG, or WebP
- Recommended size: 1920x1080 for hero images, 800x600 for experience images
- File size: Optimize images for web (under 500KB recommended)

## Usage
Images are automatically loaded from `/images/` path in the components.
